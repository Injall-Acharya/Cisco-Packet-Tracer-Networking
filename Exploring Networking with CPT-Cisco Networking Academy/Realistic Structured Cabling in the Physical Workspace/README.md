Realistic Structured Cabling in a Physical Workspace and Cabling Devices in a Rack
Overview

This activity was completed using Cisco Packet Tracer to design and implement realistic structured cabling for an office environment. The task focused on connecting end devices and network infrastructure using appropriate physical cables, organizing networking equipment inside a rack, and creating a practical physical network layout.
Objectives

    Create a realistic physical workspace for an office network.
    Place network devices and end devices in appropriate locations.
    Install and organize networking devices inside a rack.
    Select appropriate Ethernet and console cables for different connections.
    Connect computers and other end devices to network infrastructure.
    Practice physical-layer network design and structured cabling.
    Verify that devices are correctly connected.

Tools Used

    Cisco Packet Tracer
    Routers
    Switches
    PCs/end devices
    Network rack
    Ethernet cables
    Console cables
    Physical workspace components

Activities Performed
1. Created the Physical Workspace

A physical office workspace was created in Cisco Packet Tracer to represent a realistic networking environment. End-user devices and networking equipment were positioned according to their intended roles.
2. Installed Devices in the Rack

Network infrastructure devices such as switches and routers were placed appropriately inside the rack. The rack was organized to resemble a real-world network equipment installation.
3. Performed Structured Cabling

The devices were connected using appropriate physical cables. Ethernet connections were used for network communication, while console connections were used where required for device management.
4. Organized the Cabling

Cables were routed between the workstation area and networking equipment while maintaining a clean and understandable physical layout. Appropriate cable types were selected based on the interfaces being connected.
5. Verified the Connections

The completed topology was inspected to ensure that:

    All required devices were connected.
    Correct interfaces were used.
    Appropriate cable types were selected.
    Network devices were properly positioned.
    The physical layout represented a realistic office network.

Skills Demonstrated

    Cisco Packet Tracer
    Structured network cabling
    Physical network topology design
    Rack and equipment organization
    Ethernet cabling
    Console connectivity
    Network infrastructure setup
    Physical-layer troubleshooting
    Understanding of network device interfaces

Outcome

Successfully designed a realistic office physical workspace and implemented structured cabling between end devices and network infrastructure. The activity provided practical experience with physical network design, rack organization, cable selection, and device connectivity using Cisco Packet Tracer.
Conclusion
This activity strengthened my understanding of the physical layer of computer networks and how networking equipment is organized and interconnected in a real-world office environment. It also provided hands-on practice with structured cabling and Cisco networking equipment.
